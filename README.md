# MINIATYR — 미니어처 가구 공방

아이코닉 가구 100선을 미니어처로 만들기 위한 웹앱입니다. 가구 하나를 고르면 **삼면도 → 재단표·1:1 템플릿 → 조립 순서 → 실사 3D → STL 내보내기**까지 한 화면에서 이어집니다.

> 비공식 팬 프로젝트이며 IKEA와 관련이 없습니다. 제품명은 실물을 가리키기 위해서만 썼고, 치수는 참고용 근사치입니다. 100개의 순번은 편집 큐레이션이며 공식 판매 순위가 아닙니다.

## 실행

빌드 과정이 없습니다. 정적 파일을 그대로 띄우면 됩니다.

```bash
npm start
```

`http://localhost:5173` 을 엽니다. GitHub Pages처럼 정적 호스팅에 저장소 루트를 그대로 올려도 동작합니다.

```bash
npm test
```

Claude 아티팩트로 올릴 묶음은 아래 명령으로 `dist/` 에 만듭니다(three.js 는 같은 버전을 CDN에서 불러오도록 바뀝니다).

```bash
npm run artifact
```

## 무엇을 할 수 있나

| 화면 | 내용 |
| --- | --- |
| 홈 | 스크롤하면 같은 미니어처가 도면 → 재단 → 조립 → 완성으로 변하는 3D 연출, 100종 컬렉션(분류·검색·정렬), 실물 크기 비교 줄 세우기 |
| 워크벤치 | 축척(1:6–1:48)·변형·마감 선택, 실사 3D(분해·도면선 비교·치수·미니어처 모드), 도면 시트, 재단표, 조립 단계, 내보내기 |
| 만드는 법 | 축척·재료·도구·재단·접착·도색·패브릭·3D 프린트 안내 |
| 스케일 랩 | 완성 크기를 화면에 실제 크기로 표시(신용카드로 화면 보정) |
| 내 공방 | 조립 진행 기록(브라우저에만 저장), 백업 저장·불러오기 |

- **도면**: 삼면도(제3각법), 분해도+부품표, 부품도, 1:1 재단 템플릿, 조립도. 종이·청사진·야간 스타일. PDF·SVG·PNG 저장.
- **재단**: 같은 부품 묶기, 두께별 판재 배치, 각재·환봉 절단 계획, CSV·DXF 저장. "시판 재료 두께에 맞추기"를 켜면 0.5·1·1.5·2·3mm… 규격으로 모델 전체를 다시 계산합니다.
- **3D**: 절차적 PBR 재질(나뭇결·직물·금속·유리), 스튜디오 조명, 멈추면 샘플을 누적해 면광원 그림자와 주변광 차폐가 수렴하는 렌더. 미니어처 모드에서는 커팅 매트·15cm 자·500원 동전과 함께 실제 크기 비례로 보여 줍니다.
- **내보내기**: 완성형 STL, 부품 키트 STL(눕혀 배치), OBJ+MTL, 고품질 PNG.

## 구조

```
index.html          앱 셸
styles/app.css      디자인 시스템(토큰·컴포넌트)
src/core/           순수 함수 코어: 기하 커널, 부품 DSL, 투영, 도면, 재단, 내보내기
src/builders/       가구 구조별 빌더(수납장·선반·테이블·의자·소파·침대·특수)
src/data/           카탈로그 100종, 재질 표
src/three/          실사 스테이지(three.js): 텍스처, 재질, 메시 변환, 렌더 파이프라인
src/ui/             화면(홈·워크벤치·가이드·스케일 랩·내 공방)
assets/thumbs/      미리 렌더한 실사 썸네일(`npm run thumbs`로 다시 생성)
tools/              개발 도구(정적 서버, 썸네일 렌더, 점검용 스크린샷)
tests/              코어 단위 테스트
```

설계 설명은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), 디자인 시스템은 [docs/DESIGN_SYSTEM.md](docs/DESIGN_SYSTEM.md)에 있습니다.
